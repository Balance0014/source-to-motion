# Source to Motion Skill

This is the small installable skill. It includes the workflow, local render and verification scripts, references, and fonts. The full gallery and editable example projects remain on the [main branch](https://github.com/Balance0014/source-to-motion).

Run the scripts from this directory after installing the dependencies in `requirements.txt`. Browser scenes also need `requirements-browser.txt` and Chromium. Your agent/API access is your own; these scripts include no hosted rendering service or bundled API key.
