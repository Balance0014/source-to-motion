# Changelog

## v0.3.0 — 2026-10-08

- Reworked the skill's art-direction gate: research the product mechanism and industry, compare two visual approaches, then storyboard distinct camera, motion, and peripheral facts before rendering.
- Added optional local browser-canvas/FFmpeg renderer for authored scenes and a three-frame preview tool; the original Pillow renderer remains supported.
- Added four 1080×1350 source-backed films: uv dependency traversal, DuckDB file-to-query flow, Tailscale illustrative private mesh, and a redesigned GapMine evidence-to-opportunity reveal.
- Added direction briefs, editable scenes, evidence manifests, audio, MP4s, and contact sheets for all four cases; identified the earlier shared-layout films as a first-generation baseline.

## v0.2.0 — 2026-10-08

- Added the 4:5 GapMine cinematic concept film with source-checked public homepage numbers, visible signal flow, and original audio.
- Added six GitHub showcase films with distinct central scenes and source-backed product details in the surrounding dashboard. Repository Stars and Forks are labeled as dated GitHub snapshots.
- Added a source → transformation → output visual gate, a mobile-size review gate, and a requirement that dashboard panels contain real product facts rather than decorative charts.
- Added evidence manifests and verification coverage for all six GitHub films; accepted thousands separators while still rejecting altered numeric values.

## v0.1.0 — first public release

- Source-backed agent workflow for short editable motion videos.
- Local ingestion for GitHub, websites, PDF, DOCX, text, and optional OCR images.
- Pillow/FFmpeg rendering, original procedural audio, and evidence/video checks.
- Cinematic uv example and English/Chinese dashboard examples from a fictional Word brief.
- Full English and Simplified Chinese READMEs, translation rules, privacy notes, and a social preview asset.
- Automated tests on Python 3.11 and 3.12.
