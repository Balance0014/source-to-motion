# Changelog

## v0.1.0 — first public release

- Source-backed agent workflow for short editable motion videos.
- Local ingestion for GitHub, websites, PDF, DOCX, text, and optional OCR images.
- Pillow/FFmpeg rendering, original procedural audio, and evidence/video checks.
- Cinematic uv example and English/Chinese dashboard examples from a fictional Word brief.
- Full English and Simplified Chinese READMEs, translation rules, privacy notes, and a social preview asset.
- Automated tests on Python 3.11 and 3.12.
